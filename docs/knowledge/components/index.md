# Components & Utilities

Index of custom tooling, scripts, and validators.

* [blogq (Blog Post Validator)](blogq.md) - Python CLI that enforces JSON Schema and semantic rules on `posts.json`; includes unit tests under `tools/blogq/tests/`.
* [Static Generators](static_generators.md) - Node utilities that emit `api/`, `posts/*.html`, `feed.xml`, `sitemap.xml`, and `assets/js/build-id.js` from `posts.json`.
